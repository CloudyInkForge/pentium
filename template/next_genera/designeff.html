这是一份“读模板”的说明页，不是杂志成品页。它用简图表示页面结构、栏格、订口、页眉镜像与图文关系， 适合与 PDF 效果页对照阅读。示意图只表达结构比例，不按真实字号；灰色斜纹块代表图片，横线代表正文， 黑色粗块代表标题，绿色竖条代表点缀/页码条，虚线代表版心或栏线。

基础规则与图例

先建立三个共同概念：单页 / 对开、订口方向、版心与栏格。 模板严格区分左页（偶数）与右页（奇数）；B 系列一个 HTML 内是两张 210×285mm 的独立页面，不是一个 420mm 大页。

A 系列 · 单页模板

A 系列每个 HTML 是一张 210×285mm 页面。下面示意图默认画右页（订口在左）； 对应的 la 左页是镜像关系。卡片中的文件名和页码用于对照 PDF。

a1 · 首页大图蒙版

010 / 011 a1la / a1ra
标题/编者按反白
右页示意；左页镜像

上半页大图 + 62% 黑蒙版，标题、作者、编者按反白压在图上；下半页三栏正文；图注在图下。标题型不设 .run，只保留 .meta。

  • 看 PDF：上半图是否满宽、反白字是否落在平稳暗部。
  • 下半三栏底端是否齐平，图注不压栏。

B 系列 · 对开跨页模板

B 系列一个 HTML 内是两张独立页面：左页偶数、右页奇数，订口在中间。 跨订口的图必须在左右两页各放一份同图、同尺寸、同裁切的 .ph，装订后才无缝。 下面简图用中间双线表示订口。

b1 · 单图跨页型

020 / 021 b1oa / b1ob
右页
对开示意：2+1、下置图带

一张跨页图横跨订口，位于版心上侧或下侧。图带宽度只有 1+1、2+1、1+2、2+2 四种；内容型黑字白底，标题型无 .run、无蒙版。

  • 看 PDF：图带两端是否落在栏线，上/下边是否贴版心。
  • 跨订口图左右两页各一份 .ph，订口处无接缝。

b2 · 多图连图型

022 / 023 b2oa / b2ob
白缝
对开示意：多图组成图带，白缝正对订口

与 b1 同一套几何，但图带由多张图组成。各图宽 + 2mm 白缝 = 图带总宽；建议一条白缝正对订口。组图注放在图带 2 栏一侧。

  • 看 PDF：白缝是否 2mm 且不描边。
  • 图片带两端仍严格对栏。

b3 · 四角跨页图型

024 / 025 b3oa / b3ob
图在右上角
对开示意：图跨订口占 4 栏

图位于对开页右上角，跨订口占多栏。内容型无蒙版；标题型图贴边、加 55% 浅蒙版，标题右对齐。左页 2 栏满高，图下 4 栏各 12 行。

  • 看 PDF：标题型蒙版是否 55% 较浅，标题是否落在暗部。
  • 图下四栏底端齐平，图注不跨订口。

b4 · 左图右文型

026 / 027 b4oa / b4ob
整页图 / 标题型可加蒙版
对开示意：左页整图，右页 a2 式内容页

左页整页出血大图；右页是一张完整 a 系列内容页（示例为 a2 式图 + 三栏）。标题型在左页加 62% 蒙版、标题和编者按；内容型左页纯图，页眉反白。

  • 看 PDF：左页图是否真正出血。
  • 右页保持完整内容页，可替换为其他 a 页。

b5 · 左图右文加宽型

028 / 029 b5oa / b5ob
右页剩两栏
对开示意：图跨入右页 1 栏

左页整页图向右跨入右页 1 栏，图总宽 285.667mm；右页剩余两栏各 54 行。标题型图幅加 62% 蒙版；页眉让出图区。

  • 看 PDF：右页图区是否占去内侧第 1 栏。
  • 右页两栏底端齐平，页眉不压图。

b6 · 组图型（纯标题型）

030 / 031 b6ob
反白直压图
对开示意：左页整图，右页 2×2 组图

纯标题型，不设蒙版。左页版心整图，标题/作者/编者按反白直压图，标题块整体右移；右页上侧 2×2 组图，图下两栏各 30 行。

  • 看 PDF：反白字是否落在图心平稳、反差足够处。
  • 组图白缝 3mm，整组左右对栏。

b7 · 超大图型（纯标题型）

032 / 033 b7ob
左页标题/编者按反白
右页下侧宽栏正文
对开示意：整幅图跨两页出血

整幅图 420×285mm 跨两页出血，左右两页各放一份；不设蒙版。左页标题/作者/编者按反白；右页正文用一栏宽栏，放在下侧贴版心下界，反白。

  • 看 PDF：整图在订口处是否无缝。
  • 右页正文是否为宽栏、不拆成密集三栏。

C 系列 · 单页短文集纳

C 系列每页容纳多个短文本。与 A 一样分 la 左页 / ra 右页； 示意图默认画右页，左页镜像。C 系列全部元素绝对锚定，不使用自动分栏。

c1 · 三组交错图文型

034 / 035 c1la / c1ra
右页示意；三组左右交替

版心纵向切三组，每组“图 2 栏 + 文本 1 栏”，相邻组左右关系交替。组高 = 10 + n×4.5736；组题 12pt + 绿线；图底、文本底、组底同一条线。

  • 看 PDF：三组是否 Σh + 2×10.168 = 247。
  • 组题、绿线在文本栏内，不跨图。

c2 · 三栏纯文本短讯型

036 / 037 c2la / c2ra
右页示意；三栏各 4 条短讯

无图，三栏通高 54 行。每栏 4 条短讯，每条“题名 1 行 + 正文 n 行 + 条距 5.7645”；题名前置绿条，条目独立绝对锚定。

  • 看 PDF：三栏底端是否齐 269。
  • 每栏 4×题名 + 3×条距 + 45 行 = 247。
