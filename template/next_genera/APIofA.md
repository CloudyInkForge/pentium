**鼓励更改可改项以灵活**

- 行数预算见 §1 栏位最后一列。实际行数 ≤ 预算；排满的栏必须用满，末栏可短。
- 断栏后的第一段用 `<p class="cont">`；`.tick` 只留在首栏第一段。
- 改字号、栏宽 → 全文重切；只改文字 → 按预算切行。
- 右页：`.run` `left:22mm`；`.meta` `right:16mm`；顺序 **栏目名 → 页码 → 绿条**。
- 左页：`.run` `right:22mm` 右对齐；`.meta` `left:16mm`；顺序 **绿条 → 页码 → 栏目名**。
- a1 与 b 亚型没有 `.run`，只有 `.meta`（右页靠右、左页靠左）。

## 校验

1. `.col` 高 = 行数 × 4.5736；排满的栏底端同一 y。
2. `.mask` 与 `.ph` 四值一致；标题页文字整块在图内。
3. 图不压字；图注不压图、不压栏；图注不跨订口。
4. 奇偶使用正确
