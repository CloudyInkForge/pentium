# APIofC.md — C 系列（单页·短文集纳）模板 API

C 系列用于**一页容纳多个短文本**（诗歌、短散文、短讯、栏目集锦）。与 B 系列不同，C 不是对开跨页：每个 HTML 是**一张独立的 `210×285mm` 页面**，与 A 系列一样按左右页分两份：

| 文件 | 位置 | 页码 | 装订侧 |
|---|---|---|---|
| `c1la` / `c2la` | 左页（偶数） | 034 / 036 | 订口在右：外白边 16、内白边 22 |
| `c1ra` / `c2ra` | 右页（奇数） | 035 / 037 | 订口在左：内白边 22、外白边 16 |

版心 `172×247`（`y 22–269`）；左页 `x 16–188`，右页 `x 22–194`。三栏 `53.667`、栏距 `5.5`：左页 `16 / 75.167 / 134.333`，右页 `22 / 81.167 / 140.333`。
正文 SimSun 8.7pt、行高 `4.5736mm`；文字仅 K；点缀色 `device-cmyk(0.88 0.10 0.92 0.08)`。**全部元素绝对锚定，禁止 CSS 自动分栏/自动排版。**
页眉镜像与 A 系列一致（左页：绿条→页码→栏目名，`.run` 右对齐；右页：栏目名→页码→绿条，`.run` 左对齐）。

---

## 1. 选择器总表

| 选择器 | 含义 | 默认 | 可改 |
|---|---|---|---|
| `.page` | 单页容器 | `210×285mm`，`overflow:hidden` | 否 |
| `.run` / `.meta` / `.h-col` / `.h-folio` / `.h-folio-bar` | 页眉题名 / 页码组 / 栏目名 / 页码 / 绿条 | 同 A 系列 | 文本 |
| `.ph` | 图框（仅 c1） | `cover` + 指定裁切点 | left/top/width/height、`background-position` |
| `.gt` / `.gbar` | c1 组题 / 组题绿线 | 12pt，单行 / `12×0.7mm` | left/top、文本 |
| `.col` | c1 组内正文栏 | 1 栏 `53.667`，行高 `4.5736` | left/top/height，需按行数计算 |
| `.it` / `.itt` / `.itk` / `.itx` | c2 条目 / 条题 / 题前绿条 / 条目正文 | 见 §3 | left/top、`height`、文本 |

**鼓励在允许范围内改组高、行数、条数与图位，但必须保持栏底齐平、图不压字。**

## 2. C1 三组交错图文型（`c1la` / `c1ra`）

版心纵向切三组，每组 **图 2 栏（`112.833`）+ 文本 1 栏（`53.667`）**，组与组之间留 `10.168mm`。三组左右关系交替：

| 组 | 图位 | 文本位 | 组顶 y | 组高 h | 图 h | 文本行数 | 文本 h |
|---|---|---|---|---|---|---|---|
| 1 | 第 1–2 栏 | 第 3 栏 | `22` | `83.178` | `83.178` | 16 | `73.1776` |
| 2 | 第 2–3 栏 | 第 1 栏 | `115.346` | `74.030` | `74.030` | 14 | `64.0304` |
| 3 | 第 1–2 栏 | 第 3 栏 | `199.544` | `69.457` | `69.457` | 13 | `59.4568` |

**几何公式**（右页坐标；左页所有 `x` 减 `6`）：

- 组高 `h = 10 + n×4.5736`（`n` = 文本行数）。
- 图：`top = 组顶`、`height = h`、`width = 112.833`；两栏起 `x`：左图 `22`（左页 `16`），右图 `81.167`（左页 `75.167`）。
- 文本栏：`top = 组顶 + 10`、`height = n×4.5736`、`width = 53.667`；栏 x 与图相反（第 3 栏 `140.333` / 左页 `134.333`，或第 1 栏 `22` / 左页 `16`）。
- 组题：`top = 组顶`、`left = 文本栏 x`，`font-size 12pt`、`line-height 5.2mm`；绿线 `top = 组顶 + 6.4`，宽 `12`、高 `0.7`。正文自组顶 `+10` 起排。
- 图底、文本底、组底三者同一条线：`组顶 + h`。

**文字容量**：组题 ≤ 12 字（`53.667` 宽、12pt 单行）；正文按 `17 字/行` 估算，`16/14/13` 行分别约 `270/235/220` 字，实际切行后用 `.col` 的 `scrollHeight` 校验，排满的组不得溢出。
**图**：三张图可用同一素材靠 `background-position` 区分裁切（示例 `32% center` / `68% center` / `50% 18%`）；也可换图，但每图仍占 2 栏、不得跨组。
**变化**：可改成 2 组（每组更多行）或 4 组（每组 8–12 行）；组高可变，但 `Σh + 2×组距 = 247`、且三组左右关系仍交替。首组也可换成“左文右图”，只要相邻组交错。

## 3. C2 三栏纯文本短讯型（`c2la` / `c2ra`）

无图，三栏通高 `247`（54 行），每栏排 4 条短讯，条目 = **题名 1 行 + 正文 n 行 + 条距**。

- 题名：`.itt` 高 `5.9736`（9.5pt，行高 `4.5736` + 与正文间距 `1.4`）；`.itk` 绿条 `0.8×3`、距左缘 0、题字左缩进 `3.6`。题名 ≤ 14 字、单行。
- 条目正文：`.itx` 自 `.it` 顶 `+5.9736` 起，高 `n×4.5736`。
- 条距 `G = 5.7645`；同栏下一条目 `top = 上一条 top + 5.9736 + n×4.5736 + G`。
- 每栏行数分配（示例）：栏 1 `12/12/11/10`、栏 2 `11/12/11/11`、栏 3 `12/11/10/12`；各栏合计 45 行，`4×5.9736 + 3×5.7645 + 45×4.5736 = 247`，栏底齐 `y269`。

右页各条目 `top`（左页 `x` 减 `6`，`top` 不变）：

| 栏 | 条目 1 | 条目 2 | 条目 3 | 条目 4 |
|---|---|---|---|---|
| 1（x 22） | `22` (12 行) | `88.6213` (12) | `155.2426` (11) | `217.2903` (10) |
| 2（x 81.167） | `22` (11) | `84.0477` (12) | `150.669` (11) | `212.7167` (11) |
| 3（x 140.333） | `22` (12) | `88.6213` (11) | `150.669` (10) | `208.1431` (12) |

**文字容量**：约 `15 字/行`（含标点避头尾），`n` 行约 `15n` 字；示例每条约 `150–175` 字。所有条目 `scrollHeight == clientHeight`。
**变化**：每栏可排 3–5 条；行数组合只要各栏合计 45 行、条距 `G` 可微调（`G = (247 − 4×5.9736 − 45×4.5736)/3 = 5.7645`）即可；可给部分条目加序号或改用两栏格（`83.25`），但需整页重算。**不允许一栏内出现未锚定的自动流**：每条独立 `.it`。

## 4. 共用规则

1. **单页而非对开**：C 每个文件只有一张 `.page`（`210×285`），`@page size:210mm 285mm`；成对使用 `la`（偶）+ `ra`（奇），不把两页做成 420mm 大页。
2. **页眉镜像**：左页 `.run` `right:22mm` 右对齐、`.meta` `left:16` 且 绿条→页码→栏目；右页 `.run` `left:22mm`、`.meta` `right:16` 且 栏目→页码→绿条。
3. **栏底齐平**：排满的栏底端同一条 y；末栏可短但不溢出。C1 三组所有文本块与图底齐；C2 三栏齐 `269`。
4. **不压字**：C1 图与文本同组但不重叠；组题、绿线在文本栏内，不跨图。
5. **颜色**：文字 K；点缀绿条不可改色；不使用蒙版、反白（C 系列无压图文字）。
6. **断行**：C1 每组独立起段（`text-indent:2em`）；C2 每条独立起段，不用 `.cont`。

## 5. 校验

1. `.col` / `.itx`：`height == n×4.5736`，`scrollHeight == clientHeight`，底端 = 组底 / 栏底。
2. 三组 `Σh + 2×10.168 = 247`；C1 每组图 `height == 组高`，图底与文本底同一 y。
3. C2 每栏 `4×5.9736 + 3×5.7645 + 行数×4.5736 = 247`；三栏底端同 `269`。
4. 页眉镜像正确；`la` 页码偶、`ra` 页码奇。
