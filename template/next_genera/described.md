# 校刊模板索引 · A 系列

> **使用任一模板前，必须先读 [APIofA.md](APIofA.md) 中该文件名的条目，并遵守其中的不变量与操作规则。本文件只做索引，不含操作细则；两者冲突时以 APIofA.md 为准。**

本批为 A 系列正文模板，共 18 个单页文件：文章首页（a1）、续页（a2–a7），每个版式都有右页与左页两型；a4、a7 另有 b 亚型（标题页）。

## 命名规则

文件名四位，全部小写：

```
系列号 + 序号 + 左右编号 + 亚型编号
   a      4      r          b   →  a4rb
```

| 位 | 取值 | 说明 |
|---|---|---|
| 1 | `a` | 系列号 |
| 2 | `1`–`7` | 版式序号 |
| 3 | `r` / `l` | `r` = 右页（奇数页），`l` = 左页（偶数页） |
| 4 | `a` / `b` | 亚型，`a` 为默认；`b` 仅 a4、a7 有，为标题页特化 |

例：`a4rb` = A 系列 4 号版式的右页、b 亚型。原 `a1` 现为 `a1ra`。

### a4 / a7 的纵向图框

- 图框上端与版心上界齐平：`top: 22mm`。
- 图框下端与「版心下界上推一行」齐平：`269 − 4.5736 = 264.426mm`，因此高度为 `242.426mm`。
- 图片不再贴页面上下边缘，四周留出白边；图注落在图片正下方：`top: 264.926mm`、`height: 3.9mm`（单行）。
- 左右方向仍按页型贴边：右页贴右边缘，左页贴左边缘。

### b 亚型（标题页）

在 a4 / a7 的图框上追加，与 a1 同一套语言：

- 图片上覆 62% 黑色蒙版（`opacity: 0.62`），覆盖整个图框。
- 题名：SimHei 21pt、行高 1.18、白色（0% 墨），在图框内**靠上居中**，`top: 46mm`，左右各内缩 12mm。
- 作者：SimSun 9.5pt，白色，题名下 3mm，同样居中。
- 编者按：白色，位于**图片左下角**，左边距 12mm，块底距图框下缘 38mm；标签 SimHei 7.8pt（字距 0.34em），正文 SimSun 8.2pt、行高 1.65。
- 标题页不排页眉跑马题名，只保留「栏目名 + 页码 + 绿色小条」。

- 版心：右页订口 22 mm（左）/ 外侧 16 mm（右）；左页外侧 16 mm（左）/ 订口 22 mm（右）；上 22 mm，下 269 mm。
- 栏宽：三栏 53.667 mm，两栏 83.25 mm，栏间距 5.5 mm；栏高按 4.5736 mm 行高取整行。
- 正文：SimSun 8.7 pt，行高 1.49（4.5736 mm），字距 0.02em，K 92%，两端对齐，首行缩进 2 字符。
- 页眉：SimHei 8 pt 跑马题名（字距 0.16em）；栏目名 8.5 pt（字距 0.24em）；页码 8.5 pt + 1×4 mm 绿色小条。

- 点缀色：CMYK(0.88 0.10 0.92 0.08)，仅用于页眉小条与段首竖条。
- 所有元素一律绝对定位，不使用 CSS 自动分栏、自动断行。

## 图框规则

1. **先缩放、再裁切**：`background-size: cover` 等比放大到覆盖图框，再由 `background-position: center` 裁掉多余部分。
2. 图片原始像素不参与排版；换任意尺寸、任意比例的图，最终只由 HTML 里的图框尺寸与裁切基点决定。
3. 每个图框上方的注释写明了缩放后尺寸、裁切比例与可调范围；改动图框宽高即改变裁切比例。
4. 占位图：`photos/showmaker.jpeg`（1200 × 800，3:2），原件位于 `D:\CloudyInkForge\pentium\unformed\photos\showmaker.jpeg`。

## 替换文案

- 每栏行数是设计基准（30 / 54 行），替换时保持同一页各栏行数一致，栏底才会平行。
- 续栏段落已标 `class="cont"`（首行不缩进），改稿时保留这一分段方式。
- 末栏可以短于基准行数，属于文章自然收尾；a4 单栏现留 3 行空、a7 单栏现留 6 行空。

## 左右页与印前

- 左右型不是整页镜像图片：图片出血方向、图注起排点、页眉文字与页码位置均按页型单独锚定；换页型请直接取对应的 `r` / `l` 文件。
- 无出血意味着压边图必须精确贴边，裁切误差无处缓冲；跨页或满版图建议另存一份四周各扩 3 mm 的版本给印厂。
- 文字仅用 K；图片保持原色，不做屏幕 RGB 转换。
- 屏幕预览（Chromium/Edge）不支持 `device-cmyk()`，反白字会显示为深色；颜色以 PEACH PDF 输出为准。
- 输出前用 PEACH PDF 逐页检查：背景图是否嵌入、K 文字是否仍为单黑、反白字是否确实为 0% 墨。
