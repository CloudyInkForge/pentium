# 校刊模板索引

本批仅含 **A 系列 · 正文续页**（a2–a7）。a1 为文章首页，保留原样未改动。

## 命名

- 系列用字母，变体用数字：`A1.html`、`A2.html`……
- 本次 `a2`–`a4` 为三栏骨架，`a5`–`a7` 为对应的两栏版本。
- 参数注释写在每个 HTML 的头部与图框旁，本文件只做索引。

## 公共参数

- 成品尺寸：210 × 285 mm，**无出血**。
- 版心：订口 22 mm，外侧 16 mm；上 22 mm，下 269 mm。
- 栏宽：三栏 53.667 mm，两栏 83.25 mm，栏间距 5.5 mm。
- 正文：SimSun 8.7 pt，行高 1.49（4.5736 mm），字距 0.02em，K 92%。
- 标题与页眉：SimHei；页眉右侧为「栏目名 + 页码 + 绿色小条」，与 a1 一致；左侧新增文章题名（续页用）。
- 点缀色：CMYK(0.88 0.10 0.92 0.08)，仅用于页眉小条与段首竖条。
- 所有元素绝对定位，不使用 CSS 自动分栏。

## 图框规则

1. **先缩放、再裁切**：`background-size: cover` 等比放大至覆盖图框，再由 `background-position: center` 裁掉多余部分。
2. 图片原始像素不参与排版；换任意尺寸、任意比例的图，最终只由 HTML 里的框尺寸与裁切基点决定。
3. 每个图框的可调范围写在图框上方的注释里；超出范围会破坏栏对位或压字。
4. 占位图：`photos/showmaker.jpeg`（1200 × 800，3:2），原件位于 `D:\CloudyInkForge\pentium\unformed\photos\showmaker.jpeg`。

## 替换文案

- 每栏行数是设计基准（30 / 54 / 48 行），替换时请保持同一页各栏行数一致，栏底才会平行。
- 续栏段落已标 `class="cont"`（首行不缩进），改稿时保留这个分段方式。
- 最后一栏允许短于基准行数，属于文章自然结束。

## 偶数页镜像

本批六页均按**奇数页（右页）**锚定：订口在左 22 mm，外缘在右 16 mm。
用到偶数页时需整体镜像：订口改到右侧 22 mm、栏序左右互换、页眉移到左侧，不能直接镜像整页图像。

## 印前提醒

- 无出血意味着所有压边图必须精确贴边，裁切误差无处缓冲；跨页或满版图建议另存一份四周各扩 3 mm 的版本给印厂。
- 文字仅用 K；图片保持原色，不做屏幕 RGB 转换。
- 输出前用 PEACH PDF 逐页检查：背景图是否嵌入、K 文字是否仍为单黑。
