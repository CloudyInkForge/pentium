# MIDDLE 模板族（template/MIDDLE/）· 单页增强模板

> 本文件夹是介于 **PRO 族**（跨页大图）与**基础族**（`template/page*.html`，
> @page 带边距、图仅 36mm 顶图或栏内小图）之间的"单页增强族"：
> 用 PRO 的全出血机制（@page margin:0 + 页内 16mm 边距），
> 但**只有一页、图占半页左右**。版式语言为简洁杂志式
> （《看天下》《环球人物》）：小字栏目名（暗红）→ 大标题（黑）→
> 一行"文｜作者"（灰）→ 一根发丝线；图注贴图下灰字，不压图。
> 规则冲突时以根目录 `agent.md` 硬约束为准；PRO 族的分栏硬性条件、
> 连图定律、PeachPDF 自检清单（`template/PRO/readme.md`）对本族同样适用。

## 一、三个模板速查

| 模板 | 形态 | 图占比 | 适用 | 示例素材（2611） |
|---|---|---|---|---|
| `middle-1.html` | 上半页满宽大图（130mm）+ 下半页标题/导语/双栏 | 约 46% | 横构图主图 + 600–1100 字短文整页收束；**亦可作后续页**（页眉换"篇名 · 续"一行，双栏容量增至约 2×25 行） | 《奥德赛》 |
| `middle-2.html` | 右侧通高竖带大图（90×258mm，顶/右缘出血）+ 左侧窄栏单列文字 | 约 31% | 人物/器物类竖图 + 900–1400 字（环球人物式人物版）；图可换贴左缘 | 《跑向更好的自己》 |
| `middle-3.html` | 上半页标题/双栏 + 下半页满宽大图（150mm）贴底 + 实底页码角标 | 约 53% | 段落感强的开篇或情绪收尾页；与 middle-1 互为镜像 | 《杨树荣》 |

换边换位：middle-1 图带改贴底 = middle-3；middle-2 竖带换左缘
（`.rail` 改 `left:0`，`.zone`/`.folio` 右移）；middle-3 图带置中 =
上下文字区各让位——机制不变，同步挪 padding 与图注即可。

## 二、共用机制

1. **页面**：`@page 210mm 285mm; margin:0`；`.page` 210×285、`overflow:hidden`
   仅作保险；文字栅格与 PRO/基础族同源（边距 16mm / 内容宽 178mm /
   双栏 86.25mm + 栏距 5.5mm / 正文 8.7pt / 1.49；middle-2 窄栏 96mm 单列例外）。
2. **⚠ 分栏硬性条件（实测 PeachPDF 0.9.23）**：多栏容器必须是 flex item
   （`.page` flex 列 + padding 定位 → `.zone` flex 列 → `.cols`
   `flex:1 1 auto; min-height:0`），且**第二栏起点必带 `.cbrk`**；
   绝对定位 / 普通流的 multicol 一律退化为窄单栏溢出。骨架同 PRO readme §一·五。
3. **图注**：一律贴图外（上或下）灰字 7.5pt，不压图；本族唯一允许压图的
   元素是 middle-3 的实底页码角标 `.chip`（同 PRO chip 机制）。
4. **页脚**：文字区页脚用细线 folio（期号左 / 页码右）；图占底边的页
   （middle-3）用 `.chip` 贴外角，同页只用一种。
5. **奇偶**：单页模板不挑奇偶、任意位置可排——这是与 PRO 跨页
   （必须偶起奇随）最大的排期自由。

## 三、与 PRO / 基础族的选用关系

- 图够大、文够重、能占偶数起点两页 → PRO 跨页；
- 图大但只值一页、或文章只有 1 张主图、或需要对版"填缝" → **MIDDLE**；
- 常规文章页、栏内小图 → 基础族。
- MIDDLE 可与基础族自由混排（同篇后续页接 `page+.html` 双栏续页机制；
  middle-1 本身即可作续页形态）。PRO 文章的续页也可用 middle-1 顶图页
  增加节奏（此时它就是该篇"续页"，不再挑内容起点）。

## 四、换图换文流程（每模板头部注释有分步细则）

1. 换图：改 `background-image`；按主体调 `background-position`；
   middle-1/3 满宽图重算裁切（cover 平面 = 210 × 显高），middle-2
   竖带重算横裁比例；DPI = 图宽px ÷ 显示宽mm ≥ 150（≥180 理想）。
2. 换文：正文只取不改（整句整段摘录，删节加"……"）；双栏第二栏起点
   加 `.cbrk`；图注 ≤ 22 字。
3. 核算：各文字区块高之和 ≤ 可用高 − 9mm；改图高时同步挪
   `.page` padding 与图注 top。
4. 路径：模板预览用 `../../2611/photos/…`；拷入期目录后改 `photos/…`。

## 五、PeachPDF 自检清单（交付前逐项）

- [ ] `@page 210mm 285mm; margin:0`；`.page` flex 列 + border-box padding。
- [ ] 全文件无 `opacity` / `filter` / `display:grid` / JS / 远程引用；颜色全 `device-cmyk`。
- [ ] 所有图块显式 `width/height` + `background-size` + `background-position` + `no-repeat`。
- [ ] 多栏容器为 flex item 且第二栏起点带 `.cbrk`（转 PDF 后抽查右栏 x ≈ 107.75mm 有文字）。
- [ ] 正文/图注不进页脚带；除 middle-3 的 `.chip` 外无任何文字压图。
- [ ] 逐页目检：图注贴图、无叠压、页底留白均匀、栏目/标题/作者行层级清楚。
