# PRO 模板族（template/PRO/）· 高级大图跨页模板

> 本文件夹是内页模板的"高级大图"扩展族，与 `template/page*.html` 基础族、
> `template/MIDDLE/`（单页增强族）并列。
> 基础族解决"常规文章页"；PRO 族解决"专题开篇跨页 / 图主导跨页"。
> 规则冲突时以根目录 `agent.md` 硬约束为准；本说明只补充 PRO 特有机制。

## 一·五、⚠ PeachPDF 分栏硬性条件（2026-10-26 实测，全族适用）

PeachPDF 0.9.23 的 multi-column **只有在两个条件同时满足时才真正分栏**：

1. 多栏容器（`.cols` / `.body`）是 **flex item**：自身 `flex:1 1 auto; min-height:0;`，
   且祖先链是 `display:flex; flex-direction:column`（如 `.page` flex 列 + `.zone` flex 列）；
2. **第二栏起点元素带 `.cbrk`**（`break-before:column`）——没有它，即使定高也不分栏。

反例（实测全部退化为"窄单栏"，内容全灌第一栏、向下溢出）：
绝对定位的 multicol 容器；普通流定高 multicol 容器；无 `.cbrk` 的 flex multicol。

> ⚠ **一代模板 pro-1/2/5 的 `.cols` 是绝对定位容器，按上表属于反例**。
> 样例文字短（18 行内）恰好塞得下单栏，故未暴露。换长文实排时必须把
> 文字区改成 pro-6/7/8 的结构：`.page`（flex 列 + padding 定位）→
> `.zone`（flex 列）→ `.cols`（flex item + `.cbrk`）。pro-3/4 无栏内长文，不受影响。

二代模板的页面骨架（直接抄）：

```css
.page { position:relative; width:210mm; height:285mm; overflow:hidden;
        display:flex; flex-direction:column; box-sizing:border-box;
        padding:<顶部让位>mm 16mm <底部让位>mm; }
.zone { flex:1 1 auto; min-height:0; display:flex; flex-direction:column; }
.cols { flex:1 1 auto; min-height:0; column-count:2; column-fill:auto; }
.cbrk { break-before:column; }   /* 第二栏起点必带，缺省不分栏 */
```

（绝对定位的图块/图注/页脚/chip 不受 flex 影响，照旧锚 `left/top/right/bottom`。）

## 二、共用机制（五个模板一致）

1. **页尺寸不变**：`@page 210mm 285mm`；PRO 用 `margin:0` 全出血（沿用封面 cover.html 机制），版心由页内 16mm 边距自控。
2. **文字栅格与基础族同源**：边距 16mm / 内容宽 178mm / 双栏 86.25mm + 栏距 5.5mm / 正文 8.7pt / 1.49；多栏一律 `column-fill:auto` + `.cbrk` 钉死切分点。
3. **颜色全部 `device-cmyk`**（hex 仅为浏览器回退行，先 hex 后 cmyk 双写，与基础族同例）；无透明度、无 filter、无 grid、无 JS、无远程资源。
4. **压图三件套**（唯一允许覆盖图片的元素，全部纯实底）：图注签 `.plate-cap*`、页码角标 `.chip`、标题面板 `.panel`。
5. **页码两种**：`.chip` 实底角标（图页用，贴外角）；`.folio` 细线页脚（文字页用，期号左/页码右）。同页只用一种。
6. **跨页方向**：左偶页在前、右奇页在后（对页即 偶|奇，如 14|15）；示例页码按刊内实际改。

## 三、连图对齐三定律（换图必读）

- **pro-3 整幅跨页**：两页同一 `background-size`（= 285 × 图宽/图高），左页 `0% 50%`、右页 `100% 50%`。
- **pro-6 顶部横带连图**：两页同一 `background-size`（= 420 × 图高px/图宽px 的带平面），纵向窗口偏移
  Y = −(图高 − 带高) × 取景比例（**两块同值负 mm**）；X：左页 `0%`、右页 `100%`。
- **pro-4 角连（顶对齐）**：两块 Y 偏移**同值**（负 mm）；X：右页 `100%`、左页 `0%`。
- **pro-5 角连（底对齐）**：各块 Y 偏移 = −(图高 − 块高)，各不相同，但都把**图像同一条底边线**钉在各块底边上；X 同上。
- ⚠ 角连图两块高度不同时，**Y 禁用百分比**（各块自解算必错位），一律负 mm。
- 装订会在订口吃掉约 1–2mm 图像；关键主体避开订口 8mm 带。

## 四、换内容流程（每模板头部注释有分步细则）

1. 换图：改 `background-image`（同一跨页连图两处必须同图）；按主体重算 `background-position`；重算共用 `background-size`。
2. 换文：正文只取不改（原文整句整段摘录，删节处加"……"）；双栏第二栏起点加 `.cbrk`；图注 ≤ 20 字。
3. 核算：各文字区块高之和 ≤ 可用高，填充率 ≤ 75%，页脚带 12mm 内不放内容。
4. 路径：模板预览用 `../../2611/photos/…`；**拷入期目录后改 `photos/…`**。
