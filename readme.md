本项目是一个使用AGENT的杂志项目，采取使用device-cmyk的HTML到pdf的工作链条。
目录遵守下述规则，你按需读取，不一定需要全量读取。
PP\peachpdf.exe是向PDF转换工具，你每次完成某HTML的修改后都需要利用其进行转换到PDF，确保能正确转换，否则检查报错并修复。此目录下只有peachpdf.exe一个核心工具。
每期存在一个4位编号，如2611，作为文件夹名，存储关于这期杂志的所有内容。
src下是未处理原始数据，可能包括原始文章。目录下必须有一个descriptor.txt，用于维护每个原始数据的处理情况，避免重复处理。
articles是处理好的每一篇文章，每篇是一个txt，目录下有content.txt，统计每一篇的名字和字数。
photos下是图片，目录下有phototags.txt，对应每一副图片的信息，主要包括属于的文章、尺寸、字数以及内容大致。
只有得到明确要求的情况下，你才可以进行下述操作：
1、整理原始数据到文每一篇文章。
2、为图片构建索引。
否则只能处理来自articles、photos下的存在于目录或有索引的文章或图片。
你主要要进行的是设计HTML，即将获取的文章和图片构建入html中或进行修改，即每期杂志文件下都有的与文件夹同名的HTML。如未说明，看完readme就停止，因为并不是每一期都需要构建或修改。
template下会有关于封面、内容页的模板，需要据此进行构建。
构建HTML必须用device-cmyk定义颜色，
主要进行的是排版，即合理的排布文章和图片，同时要修改模板里的格式相关文字。
