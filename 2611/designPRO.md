## ◆ 0. 总纲与硬性口径

### 0.1 对版法则（PRO 跨页唯一合法位置，本期第一约束）

1. PRO 跨页 = **左偶页在前、右奇页在后，奇 = 偶 + 1**（如 P20|P21）。
   即：**每组 PRO 跨页的起点页码必须为偶数**。奇起（P19|P20 等）一律禁止。
2. 锚定前置条件：正文 P01 必须落在**物理奇数页（右侧页）**。按现有
   前置结构（封面 1 页 + 卷首语 2 页 + 目录 1 页 = 4 页，偶数）成立：
   P01 = 物理第 5 页 ✓。**若前置页数改为奇数，必须在目录后补一页
   （空白 / 版权 / 广告）凑偶，否则全期 PRO 锚点整体错位。**
3. 基础页（page+.html ~ page++++.html）不挑奇偶，任意位置可排。
4. 本设计已按 1–2 逐页推演：14 组跨页起点
   P02/P06/P10/P16/P20/P30/P32/P38/P44/P52/P58/P64/P70/P72 **全为偶数** ✓。

### 0.3 文字与图块成本

- 每段行数 = ceil((段字数 + 2) / 每行字数)；缩进总开销按全文 +2%行计。
- 小标题 2 行；pro-1 右页题句 1 行 ≈ 23mm（含上下衬线）；pro-4/5 题句
  ≈ 14–17mm。
- 流内图块成本 = 图高÷4.57 + 1.3 行（图注 1 行 + 上下 margin）。
- pro-1 右页恒等式（余量须 ≥ 9mm ≈ 2 行，见 pro-1 头注）：
  `27.9 + (导语行×6.29 + 3.5) + 栏行数×4.57 + 4 + (图高 + 4.2) ≤ 248`
- pro-4 左页 zone-l（y158 起，至 273 页脚带）：题句版栏数
  `m = (115 − 15.5 − 11.4 − 4) ÷ 4.57 ≈ 18 行/栏`；去题句 ≈ 20 行/栏。
  右页 zone-r（y238 起）：`(35 − 7.7) ÷ 4.57 ≈ 5 行/栏`。
- pro-5 zone-t（16→131，高 115）／zone-r（16→71，高 55），见组 13。
- 双栏满版跨页文字容量（用于选文）：
  pro-1 右页 ≈ 1100–1400 字；pro-4 双页 ≈ 1380 字（去题句 ≈ 1490）；
  pro-5 双页 ≈ 1200–1280 字；pro-3 面板 ≈ 185 字（8 行）。

### 0.4 连图三定律（换图必算，逐组给出）

- **pro-3 整幅跨页**：共用 `background-size = (285 × 图宽 ÷ 图高) × 285mm`；
  左页 `0% 50%`、右页 `100% 50%`。
- **pro-4 角连（顶对齐）**：平面 W=340（右块 210 + 左阶梯 130）；
  `图高 = 340 × 图高px ÷ 图宽px`（两块共用）；Y 偏移两块**同值负 mm**；
  X：右块 `100%`、左块 `0%`。
- **pro-5 角连（底对齐）**：平面 W=360（左块 210 + 右阶梯 150）；
  Y_C = −(图高 − 150)、Y_D = −(图高 − 210)，各自负 mm、同底钉线。
- 两块高度不同时 Y **禁用百分比**；关键主体避开订口 8mm 带；
  装订损耗订口两侧各 1–2mm 属正常。

### 0.5 DPI 审计线（图源像素 ÷ 显示宽度）

- ≥180dpi 理想；150–180 可用；120–150 临界（目检）；<120 禁做整版
  （仅可做 ≤120mm 图块）。逐组审计见 ◆3，临界项汇总见 ◆6。
